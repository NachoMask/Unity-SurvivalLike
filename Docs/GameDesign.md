# SurvivalLike 게임 디자인 문서



> 최종 수정일: 2026-09-02

## 플레이어

### 기본 조작

| 행동 | 입력 | 설명 |
| --- | --- | --- |
| 이동 | 방향키(↑, ↓, ←, →) | 가로축과 세로축에서 각각 가장 마지막에 누른 방향을 우선한다. 두 축에 입력이 있으면 해당 방향을 조합하여 대각선으로 이동하고, 누르고 있는 방향키가 없으면 이동을 멈춘다. |
| 선택지 커서 이동 | 방향키(↑, ↓, ←, →) | 레벨업 선택 단계에서 선택지 커서를 이동한다. |
| 선택지 확정 | 스페이스 | 레벨업 선택 단계에서 커서가 가리키는 선택지를 확정한다. |

### 이동

- `PlayerController`는 플레이어의 방향 입력을 처리하고 현재 이동 방향을 결정한다.
- 가로축은 좌우 입력 중 가장 마지막에 누른 방향을, 세로축은 상하 입력 중 가장 마지막에 누른 방향을 우선한다.
- 각 축에서 우선하는 방향키를 놓으면 해당 축에서 누르고 있는 키 중 가장 마지막에 누른 방향으로 전환한다.
- 가로축과 세로축에 입력이 모두 있으면 두 방향을 조합하여 대각선으로 이동한다.
- 조합된 이동 방향을 정규화하여 직선 이동과 대각선 이동의 속도를 동일하게 유지한다.
- `PlayerCharacter`는 `PlayerController`가 결정한 이동 방향에 따라 실제 이동을 처리한다.
- `PlayerCharacter`는 가장 최근에 결정된 이동 방향을 마지막 방향으로 기록하며, 이동 입력이 없을 때도 해당 방향을 유지한다.
- 게임 시작 시 플레이어의 마지막 방향은 오른쪽이다.

### 스프라이트 및 애니메이션

- 이동 방향이 없으면 Idle 애니메이션을 재생한다.
- 이동 방향이 있으면 Move 애니메이션을 재생한다.
- 왼쪽으로 이동하면 스프라이트가 왼쪽을 향하고, 오른쪽으로 이동하면 오른쪽을 향한다.
- 위아래로만 이동할 때는 기존의 좌우 표시 방향을 유지한다.
- 게임 시작 시 플레이어의 표시 방향은 오른쪽이다.

### 공격

- 플레이어 공격은 적에게만 상호작용하며, 충돌 시 이동을 직접 막지 않고 피해와 공격별 부가 효과를 적용한다.

#### 공격 관련 능력치

- 능력치 계산 결과가 최소값보다 낮으면 최소값을 적용하며, 최대값이 있는 능력치는 최대값을 넘지 않도록 보정한다.
- 관통 횟수와 재타격 간격은 하나의 공격에 동시에 적용하지 않으며, 공격마다 둘 중 하나의 타격 방식을 적용한다.

| 능력치 | 최소값 | 최대값 | 역할 |
| --- | --- | --- | --- |
| 피해량 | 1 | - | 투사체의 피해량 |
| 쿨타임 | 0.1초 | - | 쿨타임이 줄어들면 더 자주 공격한다. |
| 투사체 수 | 1 | 20 | 투사체 수. 실제 투사체 수는 최소값 1과 최대값 20 사이로 보정한다. |
| 연사 간격 | 0.1초 | - | 투사체 생성 간격 |
| 투사체 속도 | 0.1 | - | 투사체의 이동 속도 |
| 공격 범위 | 0.1 | - | 공격이 영향을 줄 수 있는 공간적 범위. 구체적인 적용 방식은 공격마다 다르다. |
| 넉백 | 0 | - | 투사체의 진행 방향으로 적을 밀어내는 힘 |
| 관통 횟수 | 1 | - | 투사체가 타격할 수 있는 서로 다른 적의 수. 각 적에게 처음 피해를 줄 때만 1회 소모하고, 이미 피해를 준 적에게는 다시 피해를 주지 않는다. 관통 횟수를 모두 소모하면 투사체가 사라진다. |
| 지속시간 | 0.1초 | - | 공격의 유지 시간 |
| 재타격 간격 | 0.1초 | - | 관통 횟수를 적용하지 않는 투사체에 적용한다. 동일한 적에게 처음 접촉하면 즉시 피해를 주고, 접촉이 유지되는 동안 재타격 간격마다 다시 피해를 준다. 접촉이 끊어진 후 다시 접촉하면 즉시 피해를 준다. |

#### 회전 공격

- 공격 분류: 투사체
- 공격 방식: 여러 투사체가 플레이어를 중심으로 균등하게 배치되어 일정 시간 회전한다. 지속 시간이 끝나면 사라지고, 쿨타임이 지난 후 다시 나타난다.
- 적용 능력치: 피해량 / 쿨타임 / 투사체 수 / 투사체 속도 / 공격 범위 / 넉백 / 지속시간 / 재타격 간격
- 회전 방향은 시계 방향이다.
- 투사체 속도는 투사체의 공전 각속도에 적용한다.
- 공격 범위는 플레이어 중심에서 투사체 중심까지의 거리인 공전 반지름에 적용해 공격 범위가 증가할수록 공전 궤도가 커진다.
- 회전 공격에는 관통 횟수를 적용하지 않는다.
- 투사체가 적과 계속 접촉하고 있으면 재타격 간격마다 피해를 준다.

#### 발사 공격

- 공격 분류: 투사체
- 공격 방식: 공격이 시작되면 첫 번째 투사체를 즉시 발사하고 이후 투사체를 연사 간격마다 하나씩 발사한다. 마지막 투사체를 발사한 직후부터 쿨타임을 계산한다.
- 적용 능력치: 피해량 / 쿨타임 / 투사체 수 / 연사 간격 / 투사체 속도 / 공격 범위 / 넉백 / 관통 횟수
- 발사 방향은 탐지 범위 안에서 가장 가까운 적이나 플레이어가 마지막으로 이동한 방향과 같이 공격에 따라 결정한다.
- 발사 위치와 플레이어 위치가 같아 발사 방향을 정할 수 없으면 기본 방향인 위쪽으로 발사한다.
- 발사된 투사체는 정해진 발사 방향으로 직진하며, 발사 이후에는 방향을 바꾸지 않는다.
- 연사는 첫 번째 투사체를 발사한 시점부터 정해진 수의 마지막 투사체를 발사할 때까지를 의미한다.
- 발사 공격에서 공격 범위는 투사체 프리팹의 기본 크기에 적용하는 배율이다. 1이면 기본 크기이며, 값에 따라 투사체의 외형과 충돌 영역을 같은 비율로 확대하거나 축소한다.
- 투사체는 각 적에게 처음 피해를 줄 때만 관통 횟수를 1회 소모하고, 이미 피해를 준 적에게는 다시 피해를 주지 않는다.
- 관통 횟수를 모두 소모하면 투사체가 사라진다.
- 투사체가 적에게 피해를 줄 때마다 투사체의 진행 방향으로 넉백을 적용한다.
- 투사체는 플레이어 위치를 중심으로 한 재배치 경계를 넘었을 때 소멸한다.

##### 가장 가까운 적의 위치를 향하는 공격

- 한 번의 연사를 시작할 때 저장된 발사 위치를 초기화하고 가장 가까운 적의 위치를 새로 탐색한다.
- 발사 위치를 처음 확보하기 전까지 투사체 발사와 연사 진행을 보류한다. 대기 중에는 투사체 수를 소모하거나 쿨타임을 시작하지 않는다.
- 각 투사체를 발사하기 전에 탐지 결과를 확인한다. 탐지 범위 안에서 가장 가까운 적을 찾으면 탐지 시점의 적 위치를 발사 위치로 저장한다.
- 새로운 탐지 결과가 없으면 마지막으로 저장한 발사 위치를 유지하고 현재 연사를 계속한다. 저장된 위치는 적의 사망이나 탐지 범위 이탈에 영향을 받지 않는다.
- 각 투사체의 발사 방향은 발사 시점의 플레이어 위치에서 저장된 발사 위치를 향하도록 결정한다.
- 마지막 투사체를 발사하면 쿨타임을 시작한다. 쿨타임이 끝난 후 시작하는 다음 연사에서는 저장된 발사 위치를 초기화하고 새 위치를 확보해야 한다.

### 레벨업

- 레벨업이 발생하면 플레이어가 선택지 중 하나를 고르는 단계가 있다.
- 레벨업 선택 단계 동안 게임 진행을 일시정지한다.
- 선택을 확정하면 레벨업 선택 단계를 종료하고 게임을 재개한다.

## 필드 및 화면

### 필드

- 필드는 랜덤 변형 타일로 구성한다.
- 20×20 크기의 타일맵 청크 4개를 2×2 형태로 배치한다.
- 플레이어 이동에 따라 지나간 청크를 진행 방향 앞쪽으로 재배치하여 필드가 끊김 없이 이어지도록 한다.

### 카메라 추적

- 카메라는 플레이어를 추적한다.

### 픽셀 아트 출력

- 스프라이트와 타일의 기준 PPU는 32로 통일한다.
- 기준 해상도는 640×360으로 설정한다.
- 픽셀 아트가 선명하게 표시되도록 기준 해상도의 정수 배율을 우선 사용한다.

## 적

- 적은 최대 체력을 가지며 피해를 받아 현재 체력이 0이 되었을 때 처치되어 필드에서 사라진다.

### 플레이어 추적

- 적은 플레이어를 추적한다.
- 적은 현재 위치에서 플레이어 위치를 향하는 방향으로 이동한다.
- 이동 방향을 정규화하여 플레이어와의 거리에 관계없이 설정된 속도로 이동한다.
- 적의 실제 이동은 물리 업데이트에서 처리한다.

### 스프라이트

- 적 스프라이트는 플레이어가 있는 방향을 바라본다.
- 플레이어가 적의 왼쪽에 있으면 왼쪽을, 오른쪽에 있으면 오른쪽을 향한다.
- 플레이어가 적과 같은 가로 위치에 있으면 기존 표시 방향을 유지한다.

### 재배치

- 적이 플레이어를 중심으로 한 재배치 감지 영역을 벗어나면 감지 영역의 반대편으로 재배치한다.
- 재배치는 적이 영역을 벗어난 축을 기준으로 처리하며, 두 축을 동시에 벗어나면 양쪽 축 모두 재배치한다.

### 충돌

- 플레이어와 적은 서로의 이동을 막지 않고 겹칠 수 있다.
- 플레이어와 적의 접촉 이벤트가 발생할 수 있도록 물리 상호작용을 허용한다.
- 적끼리는 서로 충돌하여 겹치거나 통과하지 않는다.
- 적은 타일맵 청크와 충돌하지 않는다.

### 스폰 및 웨이브

- 적은 웨이브 데이터에 설정된 시작 시간, 종류, 수량 및 스폰 간격에 따라 스폰한다.
- 웨이브는 게임 시작 이후 누적된 게임 진행 시간을 기준으로 정의된 순서대로 시작한다.
- 각 웨이브의 적 스폰이 완료되지 않았더라도 다음 웨이브의 시작 시간이 되면 해당 웨이브를 시작할 수 있다.
- 따라서 여러 웨이브의 적 스폰이 동시에 진행될 수 있다.
- 각 적 종류의 `count`는 해당 웨이브에서 스폰할 총수량을 의미한다.
- 적은 카메라 화면 밖에 배치된 스폰 지점 중 하나를 무작위로 선택하여 스폰한다.
- 각 웨이브의 첫 번째 적은 웨이브 시작 시점에 즉시 스폰한다.
- 한 웨이브 안의 적들은 웨이브 데이터에 등록된 순서대로 스폰한다.
- 각 적 종류는 설정된 count만큼 스폰된 후 다음 적 종류로 넘어간다.
- `spawnInterval`은 해당 웨이브에서 적 한 마리를 스폰한 뒤 다음 적을 스폰하기까지의 시간이다.
- `spawnInterval`이 0이면 웨이브에 등록된 모든 적을 웨이브 시작 시점에 한꺼번에 스폰한다.
- 게임이 일시정지된 동안에는 웨이브 진행 시간과 스폰 간격 타이머도 정지한다.
